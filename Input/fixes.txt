# CLAIM DENIAL FIXES KNOWLEDGE BASE

# PURPOSE

This document contains structured remediation guidance for healthcare claim denial prevention and correction workflows. Each section represents actionable fixes that can be retrieved by a Retrieval-Augmented Generation (RAG) pipeline to ground Large Language Model responses in deterministic remediation logic.

# FORMAT

* CATEGORY
* ISSUE
* ROOT CAUSE
* DETECTION SIGNALS
* REMEDIATION STEPS
* VALIDATION CHECKS
* ESCALATION CONDITIONS
* PREVENTION STRATEGY

================================================================================
CATEGORY: DATA COMPLETENESS
===========================

ISSUE: Missing diagnosis code
ROOT CAUSE:
Diagnosis information was omitted during claim submission or mapping.

DETECTION SIGNALS:

* diagnosis_code is NULL
* diagnosis_code length invalid
* diagnosis_missing flag = 1
* completeness_score below threshold

REMEDIATION STEPS:

1. Retrieve diagnosis information from patient encounter records.
2. Verify ICD-10 code validity.
3. Ensure diagnosis supports the billed procedure.
4. Resubmit claim with corrected diagnosis coding.
5. Validate diagnosis specificity requirements.

VALIDATION CHECKS:

* ICD-10 code exists in approved code set.
* Diagnosis code matches procedure necessity.
* Diagnosis is not expired or deprecated.

ESCALATION CONDITIONS:

* Provider repeatedly submits incomplete diagnosis data.
* Diagnosis conflicts with procedure category.
* Multiple diagnosis corrections required.

PREVENTION STRATEGY:

* Enforce mandatory diagnosis validation before submission.
* Add ICD lookup validation in claim intake workflow.
* Reject incomplete claims at rules engine stage.
